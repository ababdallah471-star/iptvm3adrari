# Rachid m3a drari - Premium IPTV Landing Page

A modern, responsive static landing page for a premium IPTV streaming service.

## Features

- **Modern Design**: Dark theme with gradient accents and smooth animations
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Interactive Elements**:
  - Mobile hamburger menu
  - FAQ accordion
  - Contact form with validation
  - Smooth scrolling navigation
  - Scroll-based animations
- **No Dependencies**: Pure HTML, CSS, and vanilla JavaScript
- **Performance Optimized**: Lightweight with minimal external resources

## Sections

1. **Hero** - Eye-catching headline with stats and call-to-action
2. **Features** - 6 key features highlighting the service
3. **Channel Categories** - 6 content categories (Sports, Movies, News, Kids, Music, International)
4. **Pricing** - 3 pricing tiers (Basic, Premium, Ultimate)
5. **FAQ** - 4 frequently asked questions with accordion
6. **Contact/CTA** - Lead capture form
7. **Footer** - Navigation and branding

## Getting Started

Simply open `index.html` in any modern web browser.

```bash
# If you have a local server:
python -m http.server 8000
# Then visit: http://localhost:8000
```

## Customization

- Edit `index.html` to update content, pricing, and channel listings
- Modify `css/styles.css` to change colors, fonts, and layout
- Update `js/main.js` for additional interactivity

## Tech Stack

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
